STUDY LAB 初期版

【搭載機能】
・iPhone/iPad向けレスポンシブ画面
・ホーム画面追加用PWA設定、アイコン、簡易オフラインキャッシュ
・4択問題演習、即時採点、解説表示
・科目別出題
・間違えた問題の復習リスト
・自作問題の登録
・正答率と学習履歴
・JSONで学習データの書き出し/読み込み

【公開手順】
1. ZIPを解凍し、GitHubで新規リポジトリを作成
2. ZIP内のファイルをすべてリポジトリ直下へアップロード
3. Settings > Pages > Deploy from a branch > main / root を選択
4. 公開URLをiPhone/iPadのSafariで開く
5. 共有ボタン > ホーム画面に追加

【重要】
これは初期版です。データは端末内のブラウザに保存されます。別端末への自動同期、ログイン、PDF/PowerPoint/Wordの自動解析、AI問題生成はまだ実装していません。これらはバックエンドやAI APIの接続・設定を追加して実装します。
